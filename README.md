# Clínica W&N — Landing Page Estática

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento de Soluções para Clínica de Saúde.

## Projeto escolhido
Projeto 01 — Landing Page Estática.

## Tecnologias
- HTML5
- CSS3
- SVG para imagens ilustrativas locais

## Requisitos atendidos
- Título da aba
- Mais de 2 imagens
- Descrição dos serviços
- Equipe fictícia com 3 profissionais, foto ilustrativa e cargo
- Cabeçalhos H1, H2 e H3
- Formulário estático com Nome, E-mail, Cidade e Estado
- Layout responsivo para computador e celular

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Não é necessário servidor ou banco de dados.

## Observação
A Clínica W&N, profissionais, contatos e imagens são fictícios e foram criados exclusivamente para fins acadêmicos.
